# 뽑기 그룹 (별 갯수로 나뉨)

## ★ 뽑기 (확률 75%)
- 아이템 : 나 빼고 뒤로 달리기 1초
- 아이템 : 가속 2배
- 아이템 : 중력맨 (내 쪽으로 타인 당기기 레벨 1)
- 아이템 : 연습만이 살길 (적용시 모든 플레이어의 지금 달리는 구간이 '트랙 1'로 변경)
- 패시브 : 자연인 허명구의 가호 ('트랙 2'에서 배속 x5)
- 패시브 : 달려 달려 (내 달리기 속도 +3)
- 패시브 : 느려 느려 (남 달리기 속도 -3)

## ★★ 뽑기 (확률 25%)
- 아이템 : 나 빼고 다 멈추기 2초
- 아이템 : 가속 3배
- 아이템 : 중력맨 (내 쪽으로 타인 당기기 레벨 2)
- 아이템 : 괜찮아 (상대가 적용한 패시브 모두 제거)
- 아이템 : 안괜찮아 (램덤한 유저와 패시브 효과 상호 바꿈)
- 아이템 : 방화범 (모든 유저의 해당 구간을 '트랙 3'으로 바꿈)
- 패시브 : 달려 달려 (내 달리기 속도 +6)
- 패시브 : 느려 느려 (남 달리기 속도 -6)

## ★★★ 뽑기 (확률 12%)
- 아이템 : 나 빼고 뒤로 달리기 3초
- 아이템 : 2등 나와 (나와 2등의 트랙 바꾸기)
- 아이템 : 가속 4배
- 아이템 : 갑분주 (모두에게 1~3까지의 숫자를 역배속으로 적용, 사용자는 효과 없음)
- 아이템 : 반중력맨 (내 뒤쪽 타인 뒤로 더 밀어내기 레벨 1)
- 아이템 : 미끌 미끌 (나의 앞 2구간이 '트랙 4'로 변경)
- 패시브 : 달려 달려 (내 달리기 속도 +9)
- 패시브 : 느려 느려 (남 달리기 속도 -9)

## ★★★★ 뽑기 (확률 5%)
- 아이템 : 모두 제자리(모두 시작 위치로 돌아감), 다시 시작 뽑기는 랜덤으로 1회만 선택
- 아이템 : 구간 점프, 바로 다음 구간으로 넘어감
- 아이템 : 1등 나와 (나와 1등의 트랙 바꾸기)
- 아이템 : 반중력맨 (내 뒤쪽 타인 뒤로 더 밀어내기 레벨 2)
- 아이템 : ㅈ밥게임 (내가 1등일 경우, 모두가 해당 구간 시작 위치로 이동)
- 아이템 : 막판 ㄱ (막판스퍼트 바로 적용)
- 패시브 : 달려 달려 (내 달리기 속도 +20)
- 패시브 : 느려 느려 (남 달리기 속도 -20)

## ★★★★★ 뽑기 (확률 1%)
- 아이템 : 역전의 용사 (모두가 출발점이 목적지가 되어 역주행함, 돌아가는 구간의 트랙 효과는 적용되나, 모든 패시브는 사라짐)
- 아이템 : 지각 변동 (모두의 트랙에 랜덤하게 방해물 생성(느려짐, 3초간 막힘, 바닥 꺼짐(발로 아래트랙으로 내려감, 가장 아래트랙은 맨 위 트랙으로 감)
- 아이템 : 패트리어트 (모두에게 미사일 발사, 맞은 사용자는 트랙에 랜덤하게 떨어짐)
- 아이템 : 갑분주 (모두에게 주사위를 돌리게 한다. 1~6까지의 숫자를 배속 패시브로 얻음, 사용자는 무조건 6배)
- 패시브 : 거대화 (내몸이 거대해 지고, 모든 트랙이 하나로 합쳐져서 모두가 같은 트랙에서 달리게 됨, 트랙은 아이템이 적용된 트랙으로 5구간 모두 변경, 거대화하면 속도+15이며 추월 당한 플레이어는 밟혀서 3초간 멈춘다.)
- 패시브 : 삶은 고통 (모든 사용자의 구간이 '트랙 5'로 바뀌고, 속도가 빠를 수록 저항을 많이 받음,  화면이 어둡게 반전)

## 판정 규칙 (구현 수치)
- 뽑기 아이템은 뽑는 즉시 적용되지 않고 보유했다가 Space로 발동. 다음 뽑기 전까지만 유효(미사용 시 소멸)
- 뽑기 패시브는 뽑는 즉시 적용되고 단계적으로 누적됨. (내가 뽑은 것, 상대가 뽑은 것 모두 중첩 됨) 
- 체크포인트(5구간)마다 3장의 등급 구성은 뽑기의 별 갯수의 그룹 내의 항목에서 결정된다. 라운드 시작 시 미리 정해지며, 그 구간에 도달하는 모든 플레이어는 같은 뽑기 등급에서 선택하도록 동일하게 적용됨(조건 같게)
- 가장 확률이 낮은 등급(★★★★★)은 한 번의 3지선다 안에서 최대 1장만 등장(중복 없음)
- 5초 안에 선택하지 않으면 아무것도 선택되지 않고 다음 구간으로 넘어감
- 서로 다른 플레이어의 "나 빼고 멈추기/뒤로 달리기" 효과가 동시에 겹치면 등급이 높은 쪽이 우선, 동일 등급이면 더 나중에 발동된 쪽이 우선
- 가속 2배/3배/4배: 3초간 자기 자신에게 곱연산으로 적용(구간 배속 등 다른 효과와 곱해짐)
- 중력맨 레벨1/2: 발동 즉시 나를 제외한 전원을 내 위치와의 거리의 20%/40%만큼 내 쪽으로 한 번에 당김(순간 효과, 지속 아님)
- 반중력맨 레벨1/2: 발동 즉시 나보다 뒤에 있는 상대만 300px/600px 더 뒤로 밀어냄
- 나와 N등 트랙 바꾸기: 완주하지 않은 플레이어 중 현재 N등과 내 위치를 맞바꿈. 그 순위가 없으면 무효
- 구간 점프: 내 위치를 다음 체크포인트 지점으로 즉시 이동(도착 즉시 다음 뽑기가 자연스럽게 발생)
- 막판스퍼트 즉시 적용: 회전 연출 없이 즉시 1~6을 굴려 그 값×기본속도를 결승선까지의 고정 속도로 설정(전역 주사위 이벤트와 동일한 계산)
- 역전의 용사: 완주하지 않은 모든 플레이어(발동자 포함)의 위치를 트랙길이 기준으로 반전. 이후 레이스는 같은 결승선을 향해 평소처럼 계속됨
- 지각 변동: 나를 제외한, 완주하지 않은 각 플레이어마다 독립적으로 3가지 중 1개를 동일 확률(각 1/3)로 적용 — (1) 3초간 속도 감소, (2) 3초간 정지, (3) 레인이 한 칸 아래로 이동(맨 아래 레인은 맨 위로 순환). 레인 이동은 라운드가 끝날 때까지 유지되는 시각적 변화이며 속도에는 영향 없음
- 패트리어트: 나를 제외한, 완주하지 않은 각 플레이어를 트랙 위 임의의 위치(0~트랙길이)로 순간이동시킴
- 패시브는 선택된 항목들이 누적되게 해줘
- 플레이어 머리 위에는 속도가 계속 표시된다.(늘어나고 줄어드는 것 확인 가능)
